# Contributing to Muse Passport

Start from the `passport` branch. Describe the problem, resulting behavior and relevant verification in your pull request. Follow the applicable `AGENTS.md` instructions, preserve upstream copyrights and third-party licenses, and update the root README when user behavior changes.

Use GitHub Issues for reproducible bugs and feature requests; include board, App/firmware version, phone/Android version and sanitized logs. Never post tokens, account credentials, device backups or private signing keys.

This community project does not require the Meta CLA. Contributions to this project are under its Apache-2.0 license, except files which retain their original third-party license. Contributions submitted to the official Muse SDK separately must follow that upstream project's contribution requirements.
