# Muse Passport 1.0.2 — Android 连接诊断修复（预发布）

修正 Android App 的 Muse API 协议版本，并让连接失败提示显示具体环节，避免将账号、凭据或连接协议异常都误报为“请检查手机网络”。

## 升级方式

已有 1.0.1 发行版用户只需覆盖安装 `Muse-Passport-1.0.2.apk`。继续使用设备的 1.0.1 固件，无需重新刷机或配对。

ZIP 中更新了 APK 与使用说明；四段设备固件及完整初始化镜像均与 1.0.1 相同。完整镜像会覆盖设备配置，只用于需要重新初始化的安装场景。

## 改动

- API 请求使用协议版本 `1.0.0`，与现有 Muse Gadget 设备代码保持一致；App 版本单独标记为 `1.0.2`。
- 显示账号信息获取、设备凭据更新及保存、WebSocket、加密握手、设备注册或回复订阅等具体失败环节。
- 区分 DNS、网络超时、TLS、连接中断、HTTP 状态、API 响应格式及账号没有可用 VM 等错误；提示不包含凭据、原始响应或私有 URL。
- 凭据更新及回复订阅遇到临时服务错误时继续重试；认证拒绝仍提示检查配对。

旧版未保留此次连接失败的具体异常，无法确认 API 版本差异是原故障的唯一原因。修复版已在 Pixel 10 Pro XL / Android 17 上实测连接成功、回复订阅就绪；本次未重新验证完整语音对话或长期后台稳定性。

## 验证与兼容性

Android debug/release 构建与 lint、32 项后端和跨语言测试、Java BLE 协议测试通过。设备固件源码与 1.0.1 相同。公开包使用原发行签名，支持发行版覆盖升级；旧调试版使用另一签名，不能直接覆盖安装发行版。
