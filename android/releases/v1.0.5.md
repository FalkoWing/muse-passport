# Muse Passport 1.0.5 — 回复朗读、角色动画与朗读跟页

本次正式版包含 1.0.5 固件、Android 伴侣 App 1.0.5（versionCode 9）与 iOS 伴侣 App 1.1.0（build 3）。iOS 继续通过 TestFlight 分发，不在 GitHub 附件中。

## 新功能与修复

- Muse 回复可通过 Passport 扬声器朗读；默认使用手机本机中文语音，也可自行配置火山／豆包云端 TTS、模型资源 ID 与音色 ID，在手机上试听。
- 角色动画主页呈现空闲、聆听、思考和说话状态；阅读页每页七行，保留本轮转录与文字回复。
- 按实际音频播放进度自动跟随原文页。手动翻页暂停跟随，可从设备菜单恢复；下一条回复默认重新跟随。跨页句段保持完整，跟到段首。
- 菜单支持上下导航；重置确认页用 OK 确认、上下键取消。
- 服务明确报告仍在处理时，回复等待最多延长到本轮三分钟；缺少处理信号时仍为一分钟，语音上传确认超时不变。
- 修复阅读任务栈溢出引起的发送后重启、Android 系统 TTS 重连、连续段落语音中断，以及纯代码／图片等无可朗读正文的收尾。
- 朗读保守清理 Markdown、链接和代码；正文和阅读分页保持原文。云端预设使用当前 TTS 2.0 音色 ID，兼容迁移旧预设，并显示安全的 HTTP／服务错误码。

## 升级

请同时升级固件与伴侣 App。旧端仍兼容文字对话，不具备新朗读与跟页功能。无需新功能、当前使用正常的设备可以继续使用现有版本。

已有 Muse 固件的设备，可解压 ZIP 并按 README 使用四段固件保留现有配置和配对。首次安装使用 `Muse-Passport-1.0.5-full.bin` 从 0x0 刷入；完整镜像会清空配置与蓝牙配对，需重新设置。Android 应在系统蓝牙中清除旧设备配对；iPhone 在伴侣 App 中“移除设备”后重新添加。

Android 发行版沿用原发行证书，SHA-256：`0d304c4229c97b19fbaffe5423e294eb0a04ae38c029a453acfd41d4cadaf11c`。本机调试版与发行版签名不同，不能覆盖安装；从旧公开发行版升级使用相同发行签名。附件以 `SHA256SUMS` 校验。
